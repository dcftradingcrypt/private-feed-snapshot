    What the record tells you

    A matching hash confirms the saved bytes match the receipt. It does not prove who published the feed, when it existed, or how it travelled.

    Nym carries the capture request. Initial setup is visible to network services, and the exit can see the destination. HTTPS validation remains enabled. This tool does not promise complete anonymity.

    Choose a small feed: the Nym client buffers each response before this app checks its size. Redirects are disabled; use the final feed URL. The app does not fetch article pages, images or feed enclosures. It has no analytics or application server. Nym stores encrypted communication state in browser storage; this app uses a new namespace and in-memory passphrase on each page load. Clear site data to remove that state. Feed files stay in page memory until you save or share them.
